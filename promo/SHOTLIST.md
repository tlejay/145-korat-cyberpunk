## 1. URL

```

```

| พารามิเตอร์ | ค่า | ความหมาย |
|---|---|---|
| `demo=1` | (บังคับ) | เปิดโหมดเดโม่ — ไม่ส่งแต้มขึ้นตาราง ไม่มีรถเงา |
| `shot=` | ดูตารางข้อ 3 | ช็อตที่จะเล่น |
| `hud=` | `0` (ค่าเริ่มต้น) / `1` | ไม่มี UI เลย / มี HUD+เมนูแบบที่ผู้เล่นเห็น (ปุ่มสัมผัสซ่อนไว้) |
| `cam=` | `chase` / `fly` | กล้องเกมหลังรถ / กล้องภาพยนตร์ของช็อตนั้น — ไม่ใส่ = ค่าแนะนำของช็อต (ตาราง) |
| `wing=` | `auto` / `up` / `down` | ปีกหลัง Hidden Aero: ตามความเร็ว (กาง > 80 กม./ชม.) / กางค้าง / พับค้าง |
| `seed=` | เลขใดก็ได้ (ค่าเริ่มต้น 1) | เปลี่ยนลายฝน/ละออง — seed เดิม = ภาพเดิมทุกพิกเซล |
| `fixedDt=1` | — | หยุดนิ่ง เดินทีละเฟรมเมื่อเรียก `window.__demo.step(n)` (ใช้ตอนอัด 60 fps) |
| `quality=` | `high` (ค่าเริ่มต้น) / `medium` / `low` | ระดับกราฟิก |
| `uiScale=` | ค่าเริ่มต้น 2 ในจอแนวตั้ง | ขยาย HUD (ถ้าหน้าผลแข่งล้นจอ ลอง `1.6`) |

**Viewport แนะนำ:** 1080×1920, deviceScaleFactor 1 (แนวตั้ง 9:16) · แนวนอน 1920×1080 ก็ได้ (กล้องปรับตามสัดส่วนเอง)
**ไม่ใส่ `fixedDt`** = เปิดแล้วเล่นเองแบบ real-time 60 fps หนึ่งรอบแล้วค้างที่เฟรมสุดท้าย (`window.__demo.done = true`) — เหมาะดูตัวอย่าง/อัดจอแบบหยาบ

## 2. อัด 60 fps แบบไม่กระตุก (แนะนำ)

```bash
git clone https://github.com/tlejay/145-korat-cyberpunk && cd 145-korat-cyberpunk
pnpm install && npx playwright install chromium     # ต้องมี ffmpeg ในเครื่องด้วย
node scripts/record-demo.mjs --shot all --hud both   # → promo-footage/clean/*.mp4 + promo-footage/hud/*.mp4
node scripts/record-demo.mjs --shot drift --hud 0 --cam fly --seed 3
```

- สคริปต์เปิด Chromium 1080×1920 → `?fixedDt=1` → วน `await __demo.step(1)` + screenshot ทุกเฟรม → ffmpeg ต่อเป็น H.264 60 fps (`-crf 16`, yuv420p) — เครื่องช้าแค่ไหนวิดีโอก็ลื่น 60 fps เพราะเกมเดินตามนาฬิกาเสมือน 1/60 วิ/เฟรม
- ใช้ GPU ของเครื่อง (Mac = Metal) · ไม่มี GPU ใส่ `--gpu 0` (ช้ากว่ามาก ภาพเหมือนเดิม) · ทดสอบกับ build ในเครื่องใส่ `--base http://localhost:<port>/koratrocketcar/`
- เวลาที่ใช้บน MacBook M1 Pro: ~3.5 วิต่อ 1 วิวิดีโอ (ช็อต 6 วิ ≈ 20 วิ · `full-lap` ≈ 7 นาที)
- เขียน Playwright เองก็ได้: `await page.evaluate(() => window.__demo.ready)` → วน `__demo.frames` ครั้ง: `await page.evaluate(() => window.__demo.step(1))` แล้ว `page.screenshot()`
- `window.__demo` = `{ shot, shots, frames, fps: 60, frame, done, ready, error, step(n), info() }` — `info()` บอกตำแหน่ง/ความเร็ว/สถานะรถ (ใช้เช็กว่าวินาทีไหนเกิดอะไร)
- **เสียง:** Playwright อัดเสียงไม่ได้ → ใช้ไฟล์ใน `promo/audio/` วางเอง (เวลาเหตุการณ์อยู่ในตารางข้อ 3)

## 4. วิธีที่โหมดเดโม่ทำให้ภาพเหมือนเดิมทุกครั้ง (ไว้เล่าได้)

- เวลาในเกม (`performance.now`, requestAnimationFrame, CSS animation) ถูกแทนด้วยนาฬิกาเสมือนที่เดินทีละ 1/60 วิ · สุ่ม (`Math.random`) ใช้ seed เดียวกัน → ฝน/ละออง/ไฟกะพริบเหมือนเดิม
- ฟิสิกส์รถเดินทีละ 1/120 วิเหมือนตอนเล่นจริง · รถในช็อตถูก "ขับ" ด้วยสคริปต์ที่ส่งปุ่มเข้าทางเดียวกับปุ่มสัมผัสของผู้เล่น (ไม่ได้เซ็ตตำแหน่งรถตรง ๆ ระหว่างช็อต)
- ตรวจแล้ว: อัดช็อตเดิม 2 ครั้ง → ภาพเฟรมเดียวกันตรงกันทุกพิกเซล (md5 เท่ากัน) · `seed=7` ได้ภาพต่าง
- ช็อตเริ่มกลางเหตุการณ์ได้เพราะ "จำลองล่วงหน้าแบบไม่วาดภาพ" (pre-roll) เช่น `finish` ขับครบเกือบทั้งรอบก่อนเริ่มอัด
