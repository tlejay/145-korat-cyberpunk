## 4. สนามแข่ง 3 แบบ

สร้างจากกราฟถนน OSM จริง (Dijkstra ผ่าน waypoint, ห้ามใช้ถนนท่อนเดิมซ้ำ, ให้น้ำหนักถนนสายหลัก, ลงโทษการวิ่งสวนวันเวย์ ×4) · นับโค้ง = มุมเลี้ยว ≥ 30° ในหน้าต่าง 60 ม.
ทุกสนาม: **สตาร์ท/เส้นชัย = ถนนราชดำเนินหน้าอนุสาวรีย์ (x −30, y +40) มุ่งเหนือ** · ปิดวงสนิท · ไม่มีจุดตัดตัวเอง
เส้นทาง: `track-A.geojson` / `track-B.geojson` / `track-C.geojson` (LineString + Point จุดสตาร์ท + `osm_nodes` ลำดับ node จริง)

### A — วงคูเมืองตะวันตก (Ya Mo Moat Loop) · 3.36 กม. · 7 โค้ง (≥70°: 6)

ราชดำเนิน ↑ 546 ม. → **โค้งกลับ 148° ขวา** เข้ามิตรภาพ (ฝั่งขาออก) → มิตรภาพ → ~635 ม. (เลียบคูเหนือ รวมทางเชื่อม/แยก) → มนัส ↓ 917 ม. (ตรงยาวกลางเมืองเก่า) → สรรพสิทธิ์ ← 316 ม. → วัชรสฤษดิ์ ↓ 129 ม. → กำแหงสงคราม ← 304 ม. (เลียบคูใต้ด้านใน) → ราชดำเนิน ↑ 514 ม. → เส้นชัย

- **จุดเด่น:** ยาวที่สุด ได้ทั้งคูเหนือ คูใต้ และทางตรงยาว ~900 ม. (เหมาะ boost) · ผ่านหน้าอนุสาวรีย์ตอนจบรอบ · โค้งกลับหัวราชดำเนินเป็นจุดดริฟต์ไฮไลต์ · ผ่านใกล้สระแก้ว
- **ข้อเสีย:** ช่วงสรรพสิทธิ์-วัชรสฤษดิ์-กำแหงสงครามเป็นซิกแซก 3 โค้งติดกัน · ถนนมิตรภาพเป็นถนนคู่แยกฝั่งซับซ้อน (ต้องปั้นเกาะกลาง/U-turn) · **footprint ตึกหายรวม ~970 ม.** (มิตรภาพช่วง x +44 → +533 และมนัสช่วง y +42 → −283) · วิ่งสวนวันเวย์ 48 ม. ตรงโค้งกลับ
- ยาวที่สุดในสามแบบ = ข้อมูลที่ต้องปั้นมากสุด

### B — วงย่านการค้าตะวันตก (Downtown West Loop) · 2.35 กม. · 4 โค้ง (≥70°: 4)

ราชดำเนิน ↑ 124 ม. → **ซ้าย** สุรนารี ← 738 ม. → **ซ้าย** โยธา ↓ 462 ม. → **ซ้าย** จอมสุรางค์ยาตร์ → 805 ม. → **ซ้าย** ราชดำเนิน ↑ 223 ม. → เส้นชัย

- **จุดเด่น:** ถนนกว้าง (สุรนารีบางช่วง 4 เลน) ทางตรงยาว 740/800 ม. สองเส้น = ความเร็วสูงสุด · **ตึกแถวต่อเนื่องทั้งวง (footprint ครบ 100%)** เหมาะแต่งป้ายไฟนีออนแบบ cyberpunk ที่สุด · ถูกทิศวันเวย์ทั้งวง · ปั้นง่ายสุด
- **ข้อเสีย:** โค้งน้อย (4 โค้งซ้ายล้วน เหมือนวงรีสี่เหลี่ยม) อาจจืด → แก้ได้ด้วยทางลัดถนนบัวรอง (x −343 ถึง −370) เป็น chicane · เห็นอนุสาวรีย์แค่ช่วงต้น/ท้าย · ไม่ผ่านคูเมืองและประตูชุมพล

### C — สปรินต์รอบประตูชุมพล-คูใต้ (Gate & South Moat Sprint) · 2.08 กม. · 6 โค้ง (≥70°: 6) — แนะนำ
