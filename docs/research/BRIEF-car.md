# BRIEF — รถในเกม: Tesla Roadster รุ่นใหม่ (เปิดตัวราว 15–17 ต.ค. 2026)

อ่าน `docs/research/README.md` ก่อน · Tle ย้ำว่า **เรื่องนี้สำคัญมาก** ต้องศึกษาข่าวให้ครบก่อนปั้นโมเดล

## เป้าหมาย
รู้ให้ชัดว่ารถที่เพิ่งเปิดตัว "หน้าตาเป็นแบบไหน" และ "ทำอะไรได้" เพื่อปั้นโมเดล 3D + ตั้งค่าฟิสิกส์ในเกม
กล้องเกมเป็น **third-person มองท้ายรถ** (ไม่ใช่มุมในห้องโดยสาร) → **ด้านท้าย / ไฟท้าย / ล้อหลัง / สปอยเลอร์ / เงาด้านข้าง** สำคัญที่สุด

## งาน
1. ค้นข่าวการเปิดตัวล่าสุด (WebSearch โหมด extended + เว็บ Tesla ทางการ + สำนักข่าวรถยนต์หลายเจ้า) — ยืนยันวันเปิดตัวจริง ชื่อรุ่นจริง ว่ามีหลายเวอร์ชันไหม
2. **สเปกและความสามารถ** (ทุกตัวเลขต้องมีลิงก์แหล่ง · ข่าวลือ ≠ ทางการ แยกให้ชัด):
   - 0–100 กม./ชม. (0–60 mph), ความเร็วสูงสุด, แรงม้า/แรงบิด, น้ำหนัก, ขับเคลื่อน
   - **ฟีเจอร์กระโดด / ลอยตัว** (เช่น cold-gas thrusters / SpaceX package) — กลไกจริงเป็นยังไง ยกตัวได้สูงเท่าไร นานเท่าไร มีภาพ/คลิปสาธิตไหม
   - **ฟีเจอร์ออกตัวเร็ว** (launch mode ฯลฯ) — ทำงานยังไง
   - อื่น ๆ ที่เกมเอาไปใช้ได้ (หลังคาถอดได้, ไฟ, เสียง)
3. **รูปทรงสำหรับปั้นโมเดล** — ต่อมุม (หน้า, ข้าง, ท้าย, 3/4 หลัง, บน) อธิบาย: สัดส่วน (ยาว×กว้าง×สูง ฐานล้อ ถ้ามีตัวเลข), เส้นสาย, ทรงไฟท้าย/ไฟหน้า, ดีไซน์ล้อ, สีที่เปิดตัว, จุดเด่นที่ต้องมีถึงจะ "ดูออกว่าเป็นรุ่นนี้"
   - ทำ `research/car/blueprint.md` เป็นสเก็ตช์สัดส่วน (ASCII/ตัวเลข) ให้คนปั้น low-poly ตามได้
4. **ภาพข่าว**: ภาพข่าว/ภาพทางการมีลิขสิทธิ์ → ใช้เป็น **ภาพอ้างอิงในการปั้นเท่านั้น** ห้ามเอาภาพไปแปะเป็น texture ในเกม
   - แคปเก็บที่ `refs/car/` (gitignored) ตั้งชื่อตามมุม เช่น `rear-3q-<แหล่ง>.jpg` และจด URL ต้นทางทุกภาพไว้ใน REPORT
   - ภาพ CC จาก Wikimedia (ถ้ามี) เก็บที่ `research/car/img/` + จดลง `research/CREDITS.md`
5. **ข้อเสนอสำหรับเกม**: ตัวเลขฟิสิกส์ (มวล อัตราเร่ง ความเร็วสูงสุดในเกม) + กลไกปุ่ม "กระโดด" และ "ออกตัวเร็ว (boost)" ที่สมจริงตามรถจริง · ข้อสังเกตเรื่องโลโก้/เครื่องหมายการค้า Tesla (ให้ Tle ตัดสินใจ)
6. ผลรวม `research/car/REPORT.md` + `research/car/specs.json`

ถ้าหาไม่เจอว่ามีการเปิดตัวจริงในช่วงนี้ หรือข่าวขัดกัน → เขียนตรง ๆ ใน REPORT อย่าเดา
