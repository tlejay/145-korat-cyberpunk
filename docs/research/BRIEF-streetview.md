# BRIEF — Street View: เดินสำรวจถนนจริงรอบลานย่าโม

อ่าน `docs/research/README.md` ก่อน · **pane นี้เป็นตัวเดียวที่ใช้ Chrome** (โหลด skill `kiki-chrome` แล้ว `claude-in-chrome`)

## เป้าหมาย
บันทึก "หน้าตาจริง" ของถนนแต่ละช่วง ให้ทีมปั้นตึกริมถนน เฟอร์นิเจอร์ถนน และวางป้ายนีออนให้เข้ากับของจริง

## งาน
1. เปิด Google Maps Street View ไล่ถนนรอบลานย่าโม อย่างน้อย: ถนนราชดำเนิน (หน้าลาน), ถนนชุมพล, ถนนจอมพล, ถนนโพธิ์กลาง, ถนนมิตรภาพ ช่วงใกล้เมือง, ถนนเลียบคูเมืองฝั่งตะวันตก, ถนนอัษฎางค์, ถนนสุรนารี — ยืนยันชื่อจริงจากป้าย/แผนที่ก่อน ถนนไหนไม่ใช่ทางที่วิ่งได้ให้หมายเหตุไว้
2. แบ่งแต่ละถนนเป็นช่วง ~100–150 ม. ต่อช่วงจด:
   - ลิงก์ Street View + พิกัด + ปีที่ถ่าย
   - ถนน: จำนวนเลน ไป/กลับ เกาะกลาง ทางเท้า ความกว้างโดยประมาณ ไฟจราจร ทางม้าลาย
   - ริมถนนซ้าย/ขวา: ประเภทตึก (ตึกแถว/ห้าง/วัด/กำแพง) จำนวนชั้น สี วัสดุ กันสาด ป้ายร้าน (ประเภท ไม่ต้องจดชื่อแบรนด์) สายไฟ เสาไฟ ต้นไม้
   - ไอเดีย cyberpunk ที่ "แต่งทับ" ได้โดยไม่ขัดโครงสร้าง (ป้ายไฟตรงไหน โฮโลแกรมตรงไหน)
3. แคปหน้าจอเก็บที่ `refs/streetview/<ถนน>-<ช่วง>.png` (ภาพอ้างอิงภายใน — gitignored ห้ามย้ายไป research/)
4. ผลรวม `research/streetview/REPORT.md` (สรุป + ตารางต่อถนน) และ `research/streetview/segments.json` (road, segment, lat, lng, lanes, width_m, left{type,floors,color}, right{...}, props[], neon_ideas[], sv_url)
5. ถ้าเจอว่า OSM ผิด (ชื่อ/เลน/one-way) จดลงหัวข้อ "OSM ไม่ตรงของจริง"

## ข้อห้าม
ไม่กดปุ่มที่เปิด dialog · ไม่ล็อกอิน · ถ้า Chrome ไม่ตอบ 2–3 ครั้ง หยุดแล้วเขียนลง REPORT ว่าติดตรงไหน
