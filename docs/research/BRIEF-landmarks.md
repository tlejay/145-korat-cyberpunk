# BRIEF — Landmarks: แลนด์มาร์กรอบลานย่าโม (ขนาด รูปทรง ภาพอ้างอิงที่ license ใช้ได้)

อ่าน `docs/research/README.md` ก่อน

## เป้าหมาย
ให้ทีมปั้นโมเดล 3D แลนด์มาร์กสำคัญได้ใกล้ของจริงที่สุด และรู้ว่าภาพไหนเอามาใช้ในเกมได้ถูกลิขสิทธิ์

## งาน
1. ทำรายการแลนด์มาร์กในพื้นที่ (อย่างน้อย): อนุสาวรีย์ท้าวสุรนารี + ฐาน + ลาน, ประตูชุมพล, กำแพงเมือง/คูเมืองช่วงใกล้ลาน, สิ่งปลูกสร้างเด่นรอบลาน (ห้าง ตลาด วัด ศาลาว่าการ โรงแรม ตึกสูงที่มองเห็นจากลาน) — ค้นจากเว็บ + OSM + Wikipedia ไทย
2. ต่อแลนด์มาร์ก เขียน: ชื่อไทย/อังกฤษ · พิกัด · ขนาดโดยประมาณ (กว้าง ยาว สูง — บอกที่มาของตัวเลข) · รูปทรง/วัสดุ/สี · มุมที่มองเห็นจากถนน · ประวัติสั้น 1–2 ประโยค (ไว้ใช้ในหน้าโหลดเกม)
3. หาภาพอ้างอิงจาก **Wikimedia Commons** (API: `https://commons.wikimedia.org/w/api.php`) + แหล่ง CC อื่น — ดาวน์โหลดเฉพาะภาพ license CC0/CC-BY/CC-BY-SA ไปที่ `research/landmarks/img/` และจดทุกภาพลง `research/CREDITS.md` (ไฟล์, URL, ผู้ถ่าย, license)
4. ภาพที่ license ไม่ชัด / จากเว็บข่าว: ใส่แค่ลิงก์ใน REPORT ห้ามดาวน์โหลด
5. ข้อควรระวังเชิงวัฒนธรรม: ความเชื่อ/ธรรมเนียมเรื่องย่าโมที่เกมไม่ควรละเมิด (สรุปสั้น ๆ)
6. ผลรวมใน `research/landmarks/REPORT.md` + `research/landmarks/landmarks.json` (คีย์: id, name_th, name_en, lat, lng, size_m {w,d,h}, notes, refs[])
