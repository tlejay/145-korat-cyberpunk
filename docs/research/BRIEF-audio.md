# BRIEF — Audio: เพลงประกอบ + เสียงเอฟเฟกต์

อ่าน `CLAUDE.md` และ `docs/research/README.md` ก่อน

## เป้าหมาย
หาเพลงและเสียงที่เข้ากับเกมแข่งรถ cyberpunk กลางคืนในโคราช ใช้ในเกมได้ถูก license และโหลดเร็วบนมือถือ

## งาน
1. **รายการเสียงที่เกมต้องมี** (ปรับเพิ่มได้):
   - BGM: หน้าเมนู · ระหว่างแข่ง (synthwave/darksynth จังหวะเร็ว) · จบรอบ/ชนะ — ถ้าแทรกกลิ่นไทย/อีสาน (พิณ แคน) ในแบบ cyberpunk ได้จะดีมาก
   - รถ **ไฟฟ้า** (Tesla Roadster): เสียงมอเตอร์หอน (whine) ที่เปลี่ยน pitch ตามความเร็ว · ยางเสียดสี/ดริฟต์ · ชน · **ออกตัวเร็ว (boost)** · **กระโดด** (เสียงพ่นแรงดันแบบ thruster + ตอนลงพื้น)
   - บรรยากาศ: ฝน ฟ้าร้องไกล ๆ เมืองกลางคืน ป้ายนีออนช็อต
   - UI: กดปุ่ม นับถอยหลัง 3-2-1-GO ผ่าน checkpoint จบรอบ
2. หาแหล่งที่ใช้ได้จริง ตามลำดับความชอบ: **CC0** (Freesound CC0, OpenGameArt, Kenney, Pixabay Audio — เช็คเงื่อนไขล่าสุด) > CC-BY (ต้องเครดิต) · ❌ ห้าม CC-BY-NC, ห้ามเพลงที่มีลิขสิทธิ์/จาก YouTube
   - ทุกไฟล์จด: ชื่อ · URL · ผู้สร้าง · license · ความยาว → `research/audio/sources.json` และเพิ่มลง `research/CREDITS.md`
3. **ดาวน์โหลดตัวเลือกที่ดีที่สุด** (2–3 ตัวเลือกต่อรายการ) ไปที่ `research/audio/candidates/`
4. **แนวทางใช้งานในเกมให้มีประสิทธิภาพ** (เขียนข้อเสนอ ไม่ต้องเขียนโค้ดเกม):
   - ฟอร์แมต: Ogg Opus / AAC (Safari iOS) — ขนาดไฟล์และ bitrate ที่แนะนำ · งบรวมทั้งเกม (เป้า < 5 MB ตอนโหลดแรก)
   - Web Audio API: unlock เสียงตอนแตะครั้งแรกบน iOS · loop ไร้รอยต่อ · เสียงมอเตอร์ทำจาก loop เดียวปรับ playbackRate หรือ synth ด้วย oscillator (เทียบข้อดีข้อเสีย)
   - โหลดแบบลำดับ (BGM สตรีมทีหลัง, SFX สำคัญโหลดก่อน) · ปุ่มปิดเสียง/ปรับระดับเพลงกับเอฟเฟกต์แยกกัน
   - ถ้าบางเสียงหาแบบ license ใช้ได้ไม่ได้ → เสนอวิธี generate (เช่น procedural ด้วย Web Audio) แทน
5. ผลรวม `research/audio/REPORT.md` — สรุปบนสุด ≤ 15 บรรทัด + ตาราง "เสียง → ไฟล์ที่แนะนำ → license"
