## ไม่ผ่าน (เรียงตามความรุนแรง)

### MOB-03 — ลากนิ้วออกนอกปุ่มแล้วปุ่มค้าง 🔴
- ขั้นตอนทำซ้ำ: 1. เข้าแข่ง 2. นิ้วกดปุ่มเร่งค้าง 3. ไถนิ้วออกไปกลางจอ (ไม่ยกนิ้ว) → `input().throttle` ยังเป็น 1 จนกว่าจะยกนิ้ว · ใช้ได้กับ เร่ง/เบรก/กระโดด/boost
- สาเหตุ (ยืนยันด้วย event trace): จุดที่นิ้วโดนคือ `<path>` ของไอคอน SVG ข้างในปุ่ม → browser จับ pointer capture ไว้ที่ `path` · โค้ด `src/input/touch.ts` ปล่อย capture เฉพาะถ้า `b.hasPointerCapture()` (ตัวปุ่ม) จึงไม่เคยปล่อย → `pointerleave` ไม่เกิด
- แก้: ปล่อย capture จาก `e.target` (`(e.target as Element).releasePointerCapture?.(e.pointerId)`) หรือ CSS `.tbtn svg, .tbtn span { pointer-events: none }`
- หลักฐาน: `tests/qa/mobile.spec.ts` (MOB-03) · ภาพ `img/bug-mob03-slide-off-throttle-stuck.png` · ส่งกลับ pane: 🎮 game-ui

### DEP-03 — asset ที่มี hash ไม่ได้ cache ยาว 🔴
- ขั้นตอน: `vercel curl -I <preview>/koratrocketcar/assets/index-CKVjm_F7.js` → `cache-control: public, max-age=0, must-revalidate` (เกณฑ์ `max-age=31536000, immutable`) · CSS/ฟอนต์เหมือนกัน
- ที่ถูกแล้ว: `index.html` max-age=0 ✅ · `data/*.json` max-age=300 + swr ✅ · br ✅ · MIME ogg/m4a ✅
- แก้: เพิ่ม header ใน `vercel.json` สำหรับ `/(koratrocketcar/)?assets/[^/]+-[A-Za-z0-9_-]{8}\.(js|css|woff2?)` → `public, max-age=31536000, immutable` (อย่าครอบ `assets/audio/` ซึ่งไม่มี hash) · ส่งกลับ pane: backend/game-ui

### FEEL-05 — `pos.y` ตอนลงพื้นต่ำกว่าเกณฑ์ 🔴 (ขอคำตัดสิน)
- ทำซ้ำ: กระโดดที่ 60 กม./ชม. 20 ครั้ง → `pos.y` ต่ำสุด −0.124 ม. ทุกครั้ง (เกณฑ์ ≥ −0.05) · ส่วนอื่นของ FEEL-05 ผ่านหมด: สูง 3.49 ม. (เป้า 3.53 ±15%) ลอย 1.58 วิ (1.53 ±15%) แตะพื้น −3.30 ม./วิ ล้อครบ 4 ใน 0 ms ใช้ถัง 35 กดรัวไม่บินสูงขึ้น (สูงสุด 3.49)
- ความเห็น QA: −0.124 คือจุดอ้างอิงตัวรถยุบตามโช้ค ไม่เห็นรถจมพื้น · เสนอ: เกณฑ์เป็น "ล้อไม่ต่ำกว่าผิวถนน" หรือยอมให้ ≥ −0.15 ม. — **conductor เลือก** (ถ้ายอม จะถือว่าผ่าน)
