### FEEL-14 — ชนแบริเออร์แล้วรถดีดสูง 5.9 ม. 🔴
- ทำซ้ำ (`tests/qa/physics.spec.ts` FEEL-13/14 ทุกรอบ ทั้งในเครื่องและ preview): ขับตามทางมาจากถนนสรรพสิทธิ์ (s 2407) ไปหาโค้งซ้ายเข้าวัชรสฤษดิ์ ไม่เลี้ยว → ชนแบริเออร์นีออนด้านนอก **(x 292.3, z 336.7) ทิศ −105° ที่ 109 กม./ชม.** → 0.1 วิหลังชน รถพุ่งขึ้นด้วย vy ≈ +11 ม./วิ ทั้งที่ล้อยังแตะพื้น 2 ล้อ → ลอยสูงสุด **5.85 ม.** นาน ~1.5 วิ แล้วลงพื้นวิ่งต่อ
- พื้นตรงนั้นแบนจริง (heightAt = 0 ทุกจุด) → แรงดีดมาจากการตอบสนองตอนชน/โช้ค ไม่ใช่ทางลาด
- เทียบ M1 (`7beb1f7`) ขับเส้นเดียวกัน: ชนที่ 168 กม./ชม. ดีดแค่ **1.74 ม.** → M3 ชนช้ากว่าแต่ดีดสูงกว่า 3 เท่า
- อีกจุดที่เกินเล็กน้อย: โค้งเข้ามนัส (1325) 3.22 ม. — รถไถขึ้นคันดินคูเมืองจุดกระโดด (น่าจะตั้งใจ ไม่นับ)
- สงสัย: `src/car/physics.ts` `collide()` (ดันออกจากผนัง + บิดหัว `r += … * 1.6`) ร่วมกับ `vertical()` / ล้อขยับตามโช้คที่แก้ใน fix FEEL-05 (`src/car/index.ts`) — ต้องให้ car-physics ไล่ · ส่งกลับ pane: 🏎️ car-physics
- ผลกับผู้เล่น: โค้งนี้ระดับ 2 คนเล่นใหม่เลี้ยวไม่ทันชนตรงได้จริง → เห็นรถกระเด้งขึ้นฟ้า (ดูเป็นบั๊ก แต่ไม่พัง เล่นต่อได้)
