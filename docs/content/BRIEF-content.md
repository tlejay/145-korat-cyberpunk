## เป้าหมาย
Tle จะโพสต์ **Facebook** เล่าว่าวันนี้ทำเกมแข่งรถลานย่าโมสไตล์ cyberpunk ด้วย Claude Opus 5.5 ยังไง — **long form** อ่านสนุกสำหรับคนทั่วไปและสาย tech ในโคราช

## เนื้อหาที่ต้องมี (เรียงเล่าเป็นเรื่อง ไม่ใช่รายการ)
1. hook เปิด 2–3 บรรทัดแรก (บน Facebook คนเห็นก่อนกด "ดูเพิ่มเติม")
2. ไอเดีย: ถนนจริงรอบลานย่าโม + รถ Tesla Roadster รุ่นที่เพิ่งเปิดตัว 15 ต.ค. (กระโดดได้ ออกตัว 4.6g) + cyberpunk แต่ยึดของจริง
3. **วิธีทำงาน: herdr + Claude หลายตัว** — Claude ตัวหลักเป็น "วาทยากร" ไม่ลงมือเอง กระจายงานให้ "ลูกน้อง" คนละ tab แล้วตรวจงาน · Tle คุยกับวาทยากรคนเดียว · ใช้ analogy ให้คนทั่วไปเข้าใจ (เช่น วงออร์เคสตรา / ห้องครัว)
4. **ลูกน้องแต่ละตัวทำอะไร ใช้เวลากี่นาที** (ดึงจากตาราง Pane ใน LOG) — OSM, landmarks, Street View (คุม Chrome เอง), car, audio, QA, backend/leaderboard, gameplay, physics ฯลฯ · ตัวเลขจริงที่น่าสนใจ (ถนน 1,741 เส้น, ตึก 1,087 หลัง, test case 122 ข้อ, 44 ช่วงถนน …)
4.1 **(Tle สั่งเพิ่ม 19:07) ไล่ทุก pane ที่เปิดแล้วปิดไปแล้วทีละตัว** — แต่ละตัวต้องมี: ชื่อ pane · เปิดมาเพื่อภารกิจอะไร · ทำอะไรไป · **ได้อะไรกลับมา** (ผลลัพธ์/ข้อค้นพบเด่น 1–2 อย่าง เช่น ตัวเลข หรือเรื่องที่จับได้ว่าแผนที่ผิด) · ใช้เวลากี่นาที — ดึงจากตาราง "Pane ทั้งหมด" + Timeline ใน LOG เท่านั้น เรียงตามลำดับที่เปิด เขียนเป็นย่อหน้าสั้นต่อ pane (Facebook ไม่มีตาราง) · pane ที่ยังไม่ปิดให้รวมไว้ท้ายว่า "ยังทำงานอยู่ตอนเขียน"
5. **เรื่องฟิสิกส์**: 4 จุดโชว์ที่ Tle เลือก (ข้ามคูเมือง, ออกตัว 4.6g + พัดลมดูดพื้น, ดริฟต์โค้งกลับ 148°, ฝน + สายไฟแกว่ง) — เล่าว่าคำนวณจากสเปกรถจริงและขนาดคูเมืองจริง (ถ้า `docs/dev/PHYSICS.md` ยังไม่เสร็จ ใส่ `[รอตัวเลข physics]`)
6. ความ "จริงจัง" ที่คนไม่ค่อยรู้: ไม่เอาภาพ Google เข้าเกม (ToS) ใช้ OSM, เรื่องความเคารพย่าโม (ห้ามขับเข้าลาน/ทะลุประตูชุมพล), QA เป็นด่านก่อนขึ้นจริง, leaderboard ไม่ต้องสมัคร ตั้งชื่อไว้ขิงได้
7. เครื่องมือที่ใช้ (สั้น): Claude Code + Opus 5.5, herdr, OpenStreetMap, three.js, Vercel, Neon, ChatGPT วาดภาพ
8. ปิดท้าย: ลิงก์ `madebytle.com/koratrocketcar` + ชวนมาทำแต้มขึ้นกระดาน + เครดิต May Jaruwat / Ton Peerasak / Aek Prasert ตาม CLAUDE.md root ถ้าเหมาะ
9. ตัวเลขสรุป: ใช้เวลารวมกี่ชั่วโมง · Claude กี่ตัว · commit กี่ครั้ง (`git log --oneline | wc -l`) — ใส่ `[อัปเดตตอนจบ]` ถ้ายังไม่จบ

## รูปแบบ Facebook

## ⭐ มุมเล่าหลัก (Tle สั่ง 21:21) — "การทดลอง vibe coding ของจริง"
โพสต์ต้องเล่าเป็น **บันทึกการทดลอง** และตอบ 4 คำถามนี้ให้ชัด (ดึงตัวเลขจาก LOG เท่านั้น):
1. **ใช้เวลาเท่าไร · โมเดลอะไร** — เริ่ม 18:10 ถึงเวลาที่ deploy เสร็จ (ดู LOG) · Claude Opus 5.5 ทุก pane · Claude กี่ตัว (นับจากตาราง Pane) · commit กี่ครั้ง
2. **ไม่ได้ส่งรูปรถให้เลย** — Tle แค่บอกว่า "เอา Tesla Roadster ที่เพิ่งเปิดตัว" แล้ว pane car ไปหาข่าวเอง (วันเปิดตัว 15 ต.ค. ที่ฐาน SpaceX, 3 รุ่น, ระบบแก๊สเย็น) → ทำ blueprint สัดส่วน → ปั้นรถด้วยโค้ดล้วน → conductor เทียบภาพข่าวแล้วตีกลับให้แก้ด้านท้าย 1 รอบ · ควันขาวคำนวณจากฟิสิกส์ (แก๊สขยายตัวเย็น → ไอน้ำควบแน่น)
3. **วิธีทำแผนที่** — OpenStreetMap ให้แนวถนน/ตึก (ถนน 1,741 เส้น ตึก 1,087 หลัง) + Claude คุม Chrome เดิน Google Street View ทีละช่วง (81 จุด) จับได้ว่าแผนที่ผิด เช่น โค้งกลับ 148° ที่ไม่มีจริง, ชื่อถนนเลียบคูเหนือ, ประตูชุมพลรถลอดไม่ได้ · ภาพ Google ใช้ดูอ้างอิงอย่างเดียว ไม่เข้าเกม
4. **จุดขาย = vibe จริง ๆ** — ทั้งโปรเจค **ไม่ได้เปิดโปรแกรมอะไรเลยนอกจาก command line** (terminal + herdr + Claude Code) · ไม่มีโปรแกรม 3D ไม่มี Photoshop ไม่มี code editor ไม่ได้เขียนโค้ดเองสักบรรทัด · รถ ตึก ป้าย เสียงมอเตอร์ สร้างด้วยโค้ดที่ Claude เขียน · ภาพประกอบสั่ง ChatGPT ผ่าน terminal pane เหมือนกัน · Tle แค่คุย + ตัดสินใจ + ลองเล่น
- hook 2–3 บรรทัดแรกต้องชูจุด 4 (เช่น "ทั้งเกมนี้ ผมไม่ได้เปิดโปรแกรมอะไรเลยนอกจาก terminal")
- เรื่องที่ Tle เข้ามาแทรกระหว่างทาง (ป้ายสปอนเซอร์, ด่านเป่าเหล้า, ย้ายจุดสตาร์ท, รอบเดียว, ป้ายเลี้ยว, ควันขาว, เสียงพากย์ Mint) เล่าเป็นจังหวะ "PM สั่งเพิ่มกลางทางแล้วทีมรับไปทำทันที"

## ⭐ น้ำเสียง + เรื่องที่ต้องเล่าเพิ่ม (Tle สั่ง 21:35)
- **เล่าการส่งงานข้ามทีมกับ Mint** (ผู้ช่วย AI อีกเครื่องของ Tle): ขอให้ Mint พากย์เสียง → conductor เปิด issue ใน GitHub (`tlejay/mint#475`) → Mint ทำเสียงพากย์ 2 ชุด (Charlie/Liam) ส่งกลับเข้าเครื่อง + ตอบกลับเข้า pane ของ conductor เอง → Tle ฟังแล้วเลือก Charlie → pane announcer เตรียมชุดสำรอง CC0 ไว้คู่ · ต่อด้วย Mint ทำ video-story จากคลิปเกม (ถ้าทำแล้ว) — เล่าให้เห็นภาพ "AI หลายตัวส่งงานกันเหมือนทีมจริง" แบบเป็นกันเอง
- **น้ำเสียง: ให้แรงบันดาลใจ ไม่ใช่อวด**
  - ❌ ห้ามโชว์ความรู้/ศัพท์เทคนิคเพื่อให้ดูเก่ง (Pacejka, adiabatic, rigid body, draw call, instancing ฯลฯ) — ถ้าจำเป็นให้แปลเป็นภาษาคน ("ควันขาวเกิดจากแก๊สเย็นจัดเจออากาศชื้น เหมือนไอเย็นจากตู้เย็น")
  - ❌ ห้ามกดผู้อ่าน ห้ามประโยคแบบ "ใคร ๆ ก็ทำไม่ได้" "ต้องรู้ X ก่อน" "ถ้ายังเขียนโค้ดเองอยู่ก็…"
  - ✅ ถ่อมตัว เล่าแบบคนกำลังลอง — มีจังหวะพลาด/งง/ขำด้วย (เช่น เปิด localhost แล้วเจอแต่รถหมุนอยู่, พากย์ "Three, Three")
  - ❌ **ห้ามเล่าเรื่อง "AI แต่งว่า Tle เป็นเขยโคราช"** (Tle สั่ง 21:38) — ไม่พูดถึงเลยทั้งในโพสต์และวิดีโอ จะทำให้คนอ่านรู้สึกว่า "เราก็ทำได้"
  - ✅ ชวนคนที่อยากเริ่ม vibe coding: บอกว่าเริ่มจากอะไรได้ (ใช้แค่ terminal + คุยเป็นภาษาไทย) · ปิดท้ายด้วยการชวนลอง ไม่ใช่ขายของ
  - ตัวเลขใช้เฉพาะที่ช่วยเล่าเรื่อง (เวลา, จำนวน Claude, 1 รอบ 3.3 กม.) ไม่ต้องอัดตัวเลขเทคนิค
