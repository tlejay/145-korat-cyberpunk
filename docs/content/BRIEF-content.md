# BRIEF — Content: โพสต์ Facebook long form เบื้องหลังการทำเกม

อ่าน `CLAUDE.md` (โดยเฉพาะหัวข้อ 1, 2, 10) + `docs/making-of/LOG.md` (แหล่งข้อมูลหลัก) + `SYNC.md` + สรุปบนสุดของทุก REPORT ใน `research/` และ `docs/` ก่อน · ห้าม commit · ห้ามโพสต์เอง

## เป้าหมาย
Tle จะโพสต์ **Facebook** เล่าว่าวันนี้ทำเกมแข่งรถลานย่าโมสไตล์ cyberpunk ด้วย Claude Opus 5.5 ยังไง — **long form** อ่านสนุกสำหรับคนทั่วไปและสาย tech ในโคราช

## เนื้อหาที่ต้องมี (เรียงเล่าเป็นเรื่อง ไม่ใช่รายการ)
1. hook เปิด 2–3 บรรทัดแรก (บน Facebook คนเห็นก่อนกด "ดูเพิ่มเติม")
2. ไอเดีย: ถนนจริงรอบลานย่าโม + รถ Tesla Roadster รุ่นที่เพิ่งเปิดตัว 15 ต.ค. (กระโดดได้ ออกตัว 4.6g) + cyberpunk แต่ยึดของจริง
3. **วิธีทำงาน: herdr + Claude หลายตัว** — Claude ตัวหลักเป็น "วาทยากร" ไม่ลงมือเอง กระจายงานให้ "ลูกน้อง" คนละ tab แล้วตรวจงาน · Tle คุยกับวาทยากรคนเดียว · ใช้ analogy ให้คนทั่วไปเข้าใจ (เช่น วงออร์เคสตรา / ห้องครัว)
4. **ลูกน้องแต่ละตัวทำอะไร ใช้เวลากี่นาที** (ดึงจากตาราง Pane ใน LOG) — OSM, landmarks, Street View (คุม Chrome เอง), car, audio, QA, backend/leaderboard, gameplay, physics ฯลฯ · ตัวเลขจริงที่น่าสนใจ (ถนน 1,741 เส้น, ตึก 1,087 หลัง, test case 122 ข้อ, 44 ช่วงถนน …)
5. **เรื่องฟิสิกส์**: 4 จุดโชว์ที่ Tle เลือก (ข้ามคูเมือง, ออกตัว 4.6g + พัดลมดูดพื้น, ดริฟต์โค้งกลับ 148°, ฝน + สายไฟแกว่ง) — เล่าว่าคำนวณจากสเปกรถจริงและขนาดคูเมืองจริง (ถ้า `docs/dev/PHYSICS.md` ยังไม่เสร็จ ใส่ `[รอตัวเลข physics]`)
6. ความ "จริงจัง" ที่คนไม่ค่อยรู้: ไม่เอาภาพ Google เข้าเกม (ToS) ใช้ OSM, เรื่องความเคารพย่าโม (ห้ามขับเข้าลาน/ทะลุประตูชุมพล), QA เป็นด่านก่อนขึ้นจริง, leaderboard ไม่ต้องสมัคร ตั้งชื่อไว้ขิงได้
7. เครื่องมือที่ใช้ (สั้น): Claude Code + Opus 5.5, herdr, OpenStreetMap, three.js, Vercel, Neon, ChatGPT วาดภาพ
8. ปิดท้าย: ลิงก์ `madebytle.com/koratrocketcar` + ชวนมาทำแต้มขึ้นกระดาน + เครดิต May Jaruwat / Ton Peerasak / Aek Prasert ตาม CLAUDE.md root ถ้าเหมาะ
9. ตัวเลขสรุป: ใช้เวลารวมกี่ชั่วโมง · Claude กี่ตัว · commit กี่ครั้ง (`git log --oneline | wc -l`) — ใส่ `[อัปเดตตอนจบ]` ถ้ายังไม่จบ

## รูปแบบ Facebook
- ภาษาไทย น้ำเสียงของ Tle (PM + Tech Consultant ที่เพิ่งหัด vibe coding — เล่าแบบคนลงมือเอง ตื่นเต้นแต่ไม่โอเวอร์) · ยาว ~1,200–2,000 คำ
- Facebook **ไม่ render markdown**: ห้าม `**`, `#`, ตาราง · ใช้ย่อหน้าสั้น เว้นบรรทัด หัวข้อย่อยเป็นบรรทัดเดี่ยว ใช้ emoji นำหัวข้อได้พอประมาณ · hashtag 3–6 ตัวท้ายโพสต์
- ขัดเกลาด้วย skill `/kiki-anti-ai-fingerprint` ให้ไม่มีกลิ่น AI (ข้าม phase รออนุมัติได้ — conductor ตรวจแทน)
- ข้อเท็จจริงทุกตัวต้องตรงกับ LOG/REPORT — ห้ามแต่งตัวเลข
