# Conductor review รอบ 1 — car-model (19:10)

เทียบ `refs/car/compare-rear34.png` / `compare-chase-cam.png` กับภาพข่าว — กล้องเกมมองท้ายตลอด จุดนี้ต้องใกล้ของจริงที่สุด

แก้ (เรียงตามความสำคัญ):
1. **ไฟท้าย**: ของจริงเป็นแถบ **แดง** สว่างเต็มความกว้าง หนาขึ้น อยู่ใต้ขอบฝาท้ายพอดี — ตอนนี้เป็นเส้นส้มบาง ๆ แทบไม่เด่น · แยก emissive ให้เห็นชัดในฉากมืด (ไฟหน้าแยกชิ้นก็ได้ถ้าจำเป็น งบ draw call ขยับได้ถึง 8)
2. **แผงท้ายด้านล่าง**: ของจริงเป็น **สีดำ/เทาเข้ม** (ใต้แถบไฟลงไปถึง diffuser) ไม่ใช่แผงขาวใหญ่ — ตอนนี้ท้ายรถขาวทั้งแผ่นดูเป็นกล่อง
3. **ปีกหลัง**: ของจริงกว้างเกือบเท่าตัวรถ ยกสูงเหนือฝาท้ายชัด แผ่นโค้ง/ลาดขึ้นด้านข้าง สีเงิน-บรอนซ์โลหะ มี endplate — ตอนนี้แบน สีน้ำตาลทึบ
4. **ล้อหลัง/ยาง**: ของจริงเห็นยางหลังกว้างขนาบ diffuser ชัด — เพิ่มความกว้างยาง + ขอบล้อ/ยางสีเทาให้แยกจากฉากมืดได้
5. **หัวพ่นข้างล้อหลัง 2 หัว (พ่นลงพื้น)** — มีในภาพข่าว และเป็นจุดโชว์ตอนกระโดด/ออกตัว **ใส่เลย** แล้ว export เพิ่มใน `nozzles` (ระบุชื่อ/ประเภท `rear` vs `side-down`)
6. diffuser: หัวพ่น 4 หัวอยู่แถวบน พัดลม 4 ตัวในกรอบแถวล่าง (ตอนนี้ใกล้แล้ว) · กรอบ diffuser ยื่นลงต่ำแบบของจริง

ชื่อรถในเกม: **ราชสีห์ R1** (conductor เลือกตามที่แนะนำ — Tle มอบสิทธิ์ตัดสินใจ M1–M3) · ป้ายทะเบียนคงไว้ได้
