**เจ้าของไฟล์:** `src/track/landmarks/**` (สร้างใหม่) — export `buildLandmarks(data): THREE.Group` ให้ pane streetscape เรียกจาก loadTrack (บอกวิธีต่อใน REPORT) · ห้ามแก้ไฟล์อื่นใน src/track
1. **อนุสาวรีย์ท้าวสุรนารี**: ลานยกระดับ 26×26 ม. + แท่นสีขาว + รูปหล่อสำริด 1.85 ม. หันหน้าตะวันตก มือขวาถือดาบปลายจรดพื้น มือซ้ายเท้าสะเอว — low-poly แต่สง่างาม **ห้ามดูตลก/ล้อเลียน** · ไฟส่องสวยที่สุดในฉาก · พวงมาลัย/ดอกไม้ถวายรอบฐานแบบเรียบ ๆ
2. **ประตูชุมพล** 43×11 ม. กำแพงขาวสูง ~6 ม. ใบเสมาโค้ง ช่องประตู ~3 ม. มีบันได+รั้ว (รถลอดไม่ได้) หอรบไม้สีแดงเลือดหมู หลังคาไทยกระเบื้องดินเผา สูงรวม ~13 ม. · กำแพงเมืองขาวใบเสมาต่อไปตามแนวคูช่วงที่สนามผ่าน
3. **คูเมือง** ขอบปูน ผิวน้ำ (shader ง่าย สะท้อนไฟได้ใน M3) · ศาลาไทย/ซุ้มประตูมุมตะวันตกเฉียงเหนือ · ซุ้มประตูวัดสุทธจินดา · สระน้ำพุหัวถนนสรรพสิทธิ์ · โรงแรมจอมสุรางค์ ~11 ชั้น · ตึกโคโลเนียลขาวคู่แยกพลแสน · Terminal 21 บนขอบฟ้า (ทรงจากข้อมูลที่มี ถ้าภาพไม่พอทำทรงกลาง ๆ)
4. งบเพิ่มรวม ≤ 40 draw calls / ≤ 120k triangles · merge ตามวัสดุ
5. ภาพเทียบ: แคปมุมกล้องเกมผ่านลานย่าโม/ประตู/คูเมือง เทียบภาพอ้างอิง เก็บที่ `refs/m2/` แล้วบอกใน REPORT ว่าเหมือน/ต่างตรงไหน
