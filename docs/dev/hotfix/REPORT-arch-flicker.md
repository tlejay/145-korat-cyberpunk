# REPORT — Hotfix: ภาพกะพริบใต้ซุ้มประตูชุมพล · v0.3.1-build004 · 2026-10-18

## สรุป (บนสุด)
- **สาเหตุจริง:** z-fighting ไม่ใช่ shadow acne (เกมไม่มีเงาเรียลไทม์) — แผ่นไม้บุผนังช่องทางเดินของประตูชุมพล (`yamo.ts`) วางอยู่ "ใน" เสาปูน ผิวด้านในจึงอยู่ระนาบเดียวกับผนังปูนพอดี (0 มม.) → GPU เลือกสีปูนกับสีไม้สลับกันตามกล้องที่ขยับทีละนิด = ลายทแยง/moiré ทุกเฟรม
- **แก้:** ขยับแผ่นไม้ออกมาอยู่หน้าผนังปูน 10 ซม. (ช่องประตูแคบลงข้างละ 10 ซม.) ไม่ต้องใช้ polygonOffset
- **ไล่หาทั้งฉาก (ข้อ 2)** ด้วยสคริปต์สแกนผิวที่หันทางเดียวกัน ห่างกัน ≤ 5 มม. และทับกัน > 0.01 ตร.ม. ทุก mesh (147k สามเหลี่ยม) เจอและแก้เพิ่ม 4 จุด:
  1. ตึกโพธิ์แสนฝั่งตะวันออก (ตัว L) วาดซ้ำ 2 ชั้น: ตึกจาก OSM ไม่ถูกตัด เพราะจุดกึ่งกลางตกในรอยเว้า → `meshes.ts` เช็คจุดที่อยู่ในตัวตึกเพิ่ม (ยืนยันแล้วว่าตัดออกแค่ตึกเดียว #67)
  2. แถบไฟ Terminal 21 (skyline ไกล ~500 ม.) ทับผนัง → ยื่นออก 30 ซม. (`offsetRing` ใหม่ใน `kit.ts`)
  3. ป้ายบั้งเลี้ยว: กรอบ LED ห่างแผ่นหลัง 5 มม. และบั้งห่างกรอบ 9 มม. → ห่างชั้นละ 2 ซม. (`wayfinding/index.ts`)
  4. บัวตึกโพธิ์แสน: ด้านบนอยู่ระนาบเดียวกับหลังคา → ยกขึ้น 2 ซม.
- ลานย่าโม อนุสาวรีย์ (`statue.ts`) ซุ้มอื่น ๆ สปอนเซอร์ และด่านตรวจ: สแกนแล้วไม่เจอผิวทับกัน
- **ตัวเลข (ช่องประตู, high):** เฟรมติดกันต่างกันเฉลี่ย **76.8 → 3.6** /255 · จุดที่กะพริบ **2,680 → 159** จาก 3,300 px (ที่เหลือคือขอบที่เลื่อนตามกล้อง 1 px ไม่ใช่การกะพริบ · ช่วงที่กล้องไม่ขยับต่างกันแค่ ~0.5) · mid: 49.8 → 3.5
