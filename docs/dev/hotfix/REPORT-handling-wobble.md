## วิธีวัด
- **ส่าย (wobble)** = หัวรถลบค่าเฉลี่ยเคลื่อนที่ 1 วิ แล้ววัด peak-to-peak (ตัดการเลี้ยวตามถนนโค้งช้า ๆ ออก เหลือแต่การโยก 1–5 Hz) · เกณฑ์ < 0.3° บนทางตรง (ราชดำเนิน, 224) — มนัสโค้ง 5° ใน 50 ม. จึงนับแค่ "แกว่งกลับทิศ" (yaw rate เปลี่ยนเครื่องหมายที่ > 1°/วิ) ต้อง 0 ตอนปล่อย ≤ 1 ตอนแตะ
- **นิ่ง** = เวลาหลังปล่อยปุ่มจน yaw rate < 1°/วิ ตลอด (หรือหมุนเท่ากับถนน) · แตะ = กดลูกศรขวา 0.1 วิ ผ่าน ramp เดียวกับปุ่มบนจอ
- ตัวเลขก่อนแก้ได้จากรันสเปกเดียวกันบนโค้ด HEAD (`git stash -- src/`)
- รัน run ทิ้งเมื่อรถเริ่มชน (ความเร็วตก > 3%/เฟรม) — ปล่อยพวงมาลัยนาน ๆ จะไปชนแบริเออร์ตรงที่ถนนโค้ง / ด่านตรวจ ซึ่งไม่ใช่การส่าย
