# REPORT M2 — 🏛️ landmarks-3d: ลานย่าโม ประตูชุมพล คูเมือง

1. **เสร็จครบตามบรีฟ** · `pnpm typecheck && pnpm build` ผ่าน · โค้ดทั้งหมดอยู่ใน `src/track/landmarks/**` ไม่ได้แตะไฟล์อื่นใน `src/track` · ไม่เพิ่ม dependency
2. **ต่อเข้าเกมแล้ว** — pane streetscape เรียก `buildLandmarks()` ใน `loadTrack` เรียบร้อย (`src/track/index.ts` บรรทัด ~74–111) ตามวิธีต่อในหัวข้อ 2 · ภาพเทียบทุกภาพถ่ายจาก track ตัวจริงที่ต่อแล้ว
3. **อนุสาวรีย์ท้าวสุรนารี:** ฐานไพที 26×26 (OSM) บันไดหินอ่อน 5 ขั้นรอบด้าน · ราวหินแกรนิต + เสาโคมกลม (เปิดฝั่งตะวันตก) · แท่นขาวเพรียวมีบัว ป้ายสำริด · โต๊ะเครื่องบูชาหน้าแท่น (ขันทอง กระถางธูป ดอกไม้) · พวงมาลัยดาวเรืองคล้องรอบแท่น · **รูปหล่อสำริด 1.85 ม. หันตะวันตก มือขวาถือดาบปลายจรดฐาน มือซ้ายเท้าสะเอว สไบพาดไหล่ซ้าย** ผิวเรียบ (smooth normals) ไม่ขยับ ไม่มี collider
4. **ไฟสวยที่สุดในฉาก:** ไฟ key สีทองนวลจากหน้าซ้าย + rim light อุ่นในวัสดุสำริด + ไฟส่องพื้น 4 ดวง + halo · หินศักดิ์สิทธิ์ (แท่น ประตู กำแพง ซุ้มวัด) ใช้วัสดุ "floodlit" สว่างอุ่นที่โคนแล้วจางขึ้นด้านบน · ไม่มีนีออนบนสิ่งศักดิ์สิทธิ์
5. **ประตูชุมพล** 43×11 ม. (OSM) กำแพงขาว ~5–5.5 ม. ใบเสมาโค้ง · ช่องประตู 3 ม. **ทะลุจริง** มีบันได 3 ขั้น + ราวเหล็กกลาง + รั้ว (รถลอดไม่ได้ทั้งภาพและ collider เดิมของ world) · ศิลาแลงโผล่รอบช่อง · ป้าย "ประตูชุมพล" ฟอนต์ไทยจริง · หอรบไม้แดงเลือดหมู หน้าต่างไฟอุ่น · หลังคาไทย 3 ตอน (กลางสูง) กระเบื้องดินเผา ปั้นลมขาว + ช่อฟ้า + ไฟประดับชายคา · สูงรวม ~13 ม. · กำแพงเมืองขาวต่อจากประตูไปเหนือ 32 ม. และไปใต้เลียบคู ~75 ม.
6. **คูเมือง:** ผิวน้ำ shader เอง (คลื่น + fresnel + สะท้อนไฟ 6 ดวง) + **hook M3** `uReflect/uReflectAmt` · ผนังตลิ่งหิน + ขอบปูน (ตั้งถอยเข้าไปในน้ำ ไม่ล้ำทางเท้า) · น้ำพุในคูตะวันตก · ระดับน้ำ = `raw.water.level` เท่ากับฟิสิกส์
7. **แลนด์มาร์กรอง:** ซุ้มประตูมุมตะวันตกเฉียงเหนือ (OSM way/549397539 + สนามหญ้า กรอบพระบรมฉายาลักษณ์สีทอง **ไม่วาดพระพักตร์** ต้นตาล) · ศาลาไทย (ยาว 1 + ซุ้มเล็ก 3 ในลาน) · ซุ้มประตูวัดสุทธจินดา (ยอดมงกุฎทอง กำแพงลูกกรง วิหารหลังคาแดง) · สระแก้วมีน้ำพุ (OSM way/187397877) · โรงแรมจอมสุรางค์ 11 ชั้น + ป้ายชื่อไทย · ตึกโคโลเนียลขาวคู่แยกพลแสน · Terminal 21 บนขอบฟ้า (ทรงกลาง ๆ — ไม่มีภาพภายนอก)
8. **งบ (ทั้งหมดของ landmarks):** **30 draw calls / 29,428 สามเหลี่ยม** (บรีฟ ≤ 40 / ≤ 120k) · ที่มองเห็นพร้อมกันในมุมขับจริง **+4 ถึง +12 calls / +2k ถึง +16k tris** · ทั้งฉากหนักสุดที่วัดได้ 43 calls / 66k tris (รวมของ streetscape)
9. **ภาพเทียบ 13 มุม** อยู่ `refs/m2/*.png` (gitignored) · เหมือน/ต่างอยู่หัวข้อ 4 · ส่วนที่ต่างจากของจริงอยู่หัวข้อ 5
10. ขอ pane อื่น: streetscape — ตรวจว่าร้านตึกแถวใน `chomsurang-forecourt` หายแล้ว · M3 — ใส่ reflection ลง `materials.water.uniforms` + `setWaterLights()` เพิ่มนีออน (หัวข้อ 6)

## 2. วิธีต่อ (streetscape ทำแล้ว — เก็บไว้อ้างอิง)

```ts
const lm = buildLandmarks(raw, { surfaceAt });          // surfaceAt ใช้กันวางต้นไม้/โคมทับถนน
const built = buildTrackMeshes(data, mats, (x, z) => lm.landmarks.claims(x, z)); // ไม่วาดตึกใน footprint ที่ claim
lm.landmarks.hideLegacy(built.root);                     // ซ่อน water/moat-banks ของ M1
built.root.add(lm);
// track.update: lm.landmarks.update(dt, camera, viewDist)  ·  quality hook: lm.landmarks.setQuality(q.tier)
```

`claimed` = ลาน ประตูชุมพล ซุ้มประตูเหนือ + สนามหญ้า ตึกพลแสน 2 หลัง โรงแรมจอมสุรางค์ + ลานหน้าโรงแรม + กล่องสังเคราะห์ของ M1 (38 ม. ที่วางคร่อมถนนมหาดไทย) สระแก้ว วิหารวัดสุทธจินดา
`update()` ทำ: เวลาน้ำ, cull ตามระยะ, น้ำพุกระเพื่อม, re-project Terminal 21 ให้อยู่ใน far plane (ย้ายมาจาก world M1)
`setQuality('low')`: ปิดไฟ key อนุสาวรีย์ (เพิ่ม emissive สำริดแทน) ปิด halo ลดคลื่นน้ำ

## 5. จุดที่ไม่ตรงของจริง (ตั้งใจ / ข้อมูลไม่พอ)

- **กำแพงเมืองต่อจากประตู** ของจริงเหลือเป็นช่วงสั้น ๆ — ทำเหนือ 32 ม. ใต้ ~75 ม. ตามบรีฟ ("ต่อไปตามแนวคูช่วงที่สนามผ่าน") ใบเสมาทั้งสองหน้า
- **ประตูชุมพลหนาเต็ม 11 ม. ตาม footprint OSM** (รวมทางลาด/ฐานกำแพง) — มุมสูงจะเห็นเป็นแท่งหนา
- **ศาลาในลาน** ตำแหน่ง/จำนวนประมาณจากภาพ (ยาว 1 ทิศใต้ + ซุ้มเล็ก 3 ทิศเหนือ)
- **Terminal 21** ไม่มีภาพภายนอก → ห้าง 34 ม. + หอ 110 ม. ทรงหอบังคับการบิน + โรงแรม 64 ม. ไฟเส้น (ไม่มีโลโก้)
- **จอมสุรางค์** OSM มีแค่จุด → ตึก 56×17 ม. ขนานถนนมหาดไทย ถอยจากมนัส 15 ม.
- โครงตึกพลแสนฝั่งตะวันตกชิดขอบทางเท้า (footprint OSM) — ตัวตรวจ "ของแข็งบนพื้นขับได้" เจอแค่ผิวหน้าตึกที่ x 525.6 (ห่างช่อง curb < 0.5 ม.) ไม่มีอะไรยื่นลงถนนที่สูง 0.25–3 ม. ส่วนอื่นผ่านหมด (โคม ต้นไม้ ป้าย กรองด้วย `surfaceAt === 'blocked'`)

## 6. สำหรับ M3

- `lm.landmarks.materials.water.uniforms`: `uReflect` (texture) + `uReflectAmt` (0..1) + `uResolution` — ใส่ planar/SSR reflection ได้ทันที · `uDetail` คลื่น
- `setWaterLights(materials, [{ pos, color }])` สูงสุด 6 ดวง (ตอนนี้: อนุสาวรีย์ ประตู ซุ้มเหนือ น้ำพุสระแก้ว ซุ้มวัด) — เพิ่มนีออนป้ายร้านได้
- `materials.flood.value` = ความแรงไฟส่องหินศักดิ์สิทธิ์ · `materials.rim.value` = rim สำริด · bloom: วัสดุ `glow`/`halo`/`jet` เป็น toneMapped false พร้อมเรือง
- ห้ามเพิ่มนีออน/โฮโลแกรมบนอนุสาวรีย์ ประตูชุมพล ซุ้มวัด กรอบพระบรมฉายาลักษณ์ (CLAUDE.md §2 + research/landmarks §5)
