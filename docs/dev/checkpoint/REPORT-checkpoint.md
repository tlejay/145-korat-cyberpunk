## 3. ฟิสิกส์ของกระเด็น

- `bodies.ts`: แต่ละชิ้นเป็นชุดจุด hull รอบจุดศูนย์ถ่วง + quaternion + inertia tensor · ชนพื้นทีละจุดด้วย impulse (restitution + แรงเสียดทาน Coulomb) → ล้ม/กลิ้ง/เด้งเองตามรูปทรง (กรวยนอนกลิ้งวน) · แคปซูลชนกันเอง · หลับเมื่อนิ่ง 0.5 วิ
- รถ = กล่อง 4.6 × 2.0 × (0.11–1.2 ม.) · substep 120 Hz และ**ประมาณตำแหน่งรถระหว่างเฟรม** กันของทะลุรถที่ 230 กม./ชม. · หน้ารถลาดทำให้ของลอยข้ามฝากระโปรง (ในภาพ smash ป้ายลอยข้ามหลังคา)
- ความเร็วที่หายไป: แรงจริงเล็กมาก (แผงกั้นที่ 120 กม./ชม. Δv จริง 0.7 กม./ชม.) → **ขยายแบบเดียวกับลม ×8 ของสายไฟ** กรวย 1.2% · A-frame 5% · แผงกั้น 6.5% ต่อชิ้น เพดาน 20% ต่อรอบที่ผ่านด่าน · event `hit` มี `physicalDvKmh` ค่าจริงให้ดู
- reset: ด่านคืนสภาพเองเมื่ออยู่ข้างหลังรถ > 60 ม. และของหยุดแล้ว (ไม่เห็นตอนคืน) + `reset()` สำหรับเริ่มเกมใหม่

## 4. วิธีต่อเข้าเกม (สำหรับ integrator)

```ts
import { createCheckpoint } from '../checkpoint/index.js';
E.cp = createCheckpoint(E.scene, track, car);              // หลัง loadWorld ได้ track + car
// ใน render() หลัง car step ของเฟรมนั้น (ก่อน fx.update):  E.cp?.update(dt);
// startRace / restart:                                    E.cp?.reset();
E.cp.events.addEventListener('approach', (e) => race.toast(e.detail.text));         // "ด่านข้างหน้า! กระโดดข้าม"
E.cp.events.addEventListener('cue', (e) => controls.setJumpHint(e.detail.jump === 'now' ? 'ok' : e.detail.jump === 'none' ? 'none' : 'short'));
E.cp.events.addEventListener('clear', (e) => { race.opt.onEvent({ type: 'combo', text: e.detail.text }); audio.play('jump' /* + vo-great-jump */); });
E.cp.events.addEventListener('smash', (e) => { race.toast(e.detail.text); audio.play('crash'); });
E.cp.events.addEventListener('hit', () => audio.play('crash'));                       // throttle เอง
```
- ระวังชนกับ hint ของคูมนัส (`updateLocks` เรียก `setJumpHint('none')` ทุกเฟรมเมื่อไม่ใกล้คู) → ให้ cue ของด่านชนะเมื่อ `cue !== 'none'`
- `stats()` → `{ ms, msP95, awake, bodies, sites[], drawCalls }` ใส่ QA hook ได้ · `sim.sites[i]` มีพิกัด/ทิศ ใช้ teleport ทดสอบ
