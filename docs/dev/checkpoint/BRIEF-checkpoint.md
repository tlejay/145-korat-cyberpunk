## กติกาที่ conductor ตั้ง (ห้ามข้าม)
- **ไม่มีตัวคนเลย** (ไม่มีตำรวจ/คนเป่า) — ด่านไม่มีคนเฝ้า · รถกระบะตำรวจจอด **ชิดขอบทาง นอกเลนแข่ง** ไฟวับแดง-น้ำเงิน เป็นฉากเฉย ๆ (static collider ห้ามกระเด็น ห้ามพัง) · ห้ามเขียนชื่อหน่วยงานจริง/ตราสัญลักษณ์ตำรวจจริง — ใช้ข้อความทั่วไป "หยุดตรวจ" "จุดสกัด" "ด่านตรวจ"
- อารมณ์ = มุกขำแบบคนโคราชแซวกันเอง ไม่ล้อเลียนเจ้าหน้าที่ ไม่ส่งเสริมเมาแล้วขับ (หน้าเครดิต/ป้ายหน้าด่านอาจมีข้อความ "ดื่มไม่ขับ" เล็ก ๆ ก็ได้)
- **ไม่ใช่ blocker**: ชนแล้วของกระเด็น รถเสียความเร็วเล็กน้อย (เช่น −10~20%) ไม่หยุด ไม่ติด ไม่ respawn
- ห่างเขตลานย่าโม/ประตู/วัด

## งาน
1. **ตำแหน่ง**: เลือกทางตรงที่เหมาะกับการกระโดดข้าม (เสนอ: ทางตรงยาวถนนมนัส หรือช่วงที่ PHYSICS บอกว่าความเร็วพอ) — ใช้ PHYSICS กระโดดสูง 3.5 ม. ลอย ~1.5 วิ คำนวณว่าด่านยาวกี่เมตรถึงข้ามพ้นได้ที่ความเร็วปกติบนช่วงนั้น · อาจทำ 1–2 ด่านต่อรอบ · อัปเดตป้าย HUD/ภาพแนะนำ "ด่านข้างหน้า! กระโดดข้าม" (ข้อความผ่าน events ให้ integrator)
2. **ของในด่าน** (low-poly ตามภาพจริง, ตัวอักษรไทยด้วย canvas + Noto Sans Thai): กรวยส้มแถบขาวมีกระบองไฟฟ้าเรือง ~10–14 อัน · ป้าย A-frame "หยุดตรวจ" ขาวแดง + ไฟไซเรนแดงบนยอด 2 ป้าย · แผงกั้นเหล็ก "จุดสกัด" 2–3 แผง · ไฟกะพริบ ≤ 3 ครั้ง/วิ
3. **ฟิสิกส์ของกระเด็น** (rigid body เบา ๆ เขียนเอง): มวลจริงโดยประมาณ (กรวย ~1–3 กก., A-frame ~8–15 กก., แผงกั้น ~10–20 กก.) · รับแรงกระแทกจากรถตามความเร็ว/มวลรถ → กระเด็น หมุน ตกพื้น เด้ง ไถล หยุด · ชนกันเองได้แบบง่าย · reset ทุกรอบใหม่ · กระบองไฟยังเรืองขณะกลิ้ง · ควันไอพ่นจากการกระโดดพัดกรวยล้มได้ถ้าเตี้ยพอ (bonus)
4. **แต้ม**: กระโดดข้ามสะอาด = แต้มสไตล์ "ข้ามด่าน" · ชนกระเด็น = ไม่มีแต้ม (หรือแต้ม "ฝ่าด่าน" เล็กน้อย — ตัดสินแบบสนุก) · ส่ง event ให้ระบบแต้ม + เสียงพากย์ (เสียง Charlie "Great jump!" ใช้ได้)
5. งบ ≤ 8 draw calls (instancing) · physics ของด่าน < 0.3 ms/เฟรมมือถือกลาง · เทสต์ headless: ชนที่ 60/120 กม./ชม. ของกระเด็น ไม่ทะลุพื้น รถไม่ติด · ภาพ/GIF `refs/m3/checkpoint-*`
