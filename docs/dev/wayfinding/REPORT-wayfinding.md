## 2. วิธีต่อเข้าเกม (สำหรับ 🌃 visuals / game-ui)

```ts
import { buildWayfinding, getUpcomingTurn } from '../wayfinding/index.js';
import { createTurnHud } from '../wayfinding/hud.js';
// src/scene/visuals.ts — หลัง buildSponsors(track) (ให้ป้ายหลบแผงสปอนเซอร์ได้) และก่อนรถวิ่ง step แรก
scene.add(buildWayfinding(track));
// HUD — ทุกเฟรมระหว่างแข่ง (race.progressM = ระยะเดียวกับที่ wayfinding ใช้)
const th = createTurnHud(hud.el);
const ev = th.update(race.progressM); if (ev) audio.play(ev);   // ติ๊ก 1 ครั้งตอนเริ่มเห็นโค้ง (+ อีกครั้งที่ 70 ม. ถ้าโค้งอันตราย)
```
- **ข้อเสนอ:** ซ่อนลูกศร `.hud-turn` เดิมของ game-ui แล้วใช้ `createTurnHud` แทน (วางตำแหน่งเดียวกัน กลางบน) — ถ้าเปิดทั้งคู่จะซ้อนกัน · หรือจะเก็บของเดิมแล้วป้อน `turn: turnForHud(race.progressM)` ก็ได้ (ระยะจะวัดถึงจุดเริ่มเลี้ยว ไม่ใช่กลางโค้ง)
- `data-qa="hud-turn-warn"` · `role="status"` · `window.__wayfinding` (เฉพาะ `?qa=1`) มี `stats` (turns, ป้ายทุกชิ้น, ที่ข้าม, งบ) ให้ QA
- `buildWayfinding` แทนที่ `track.barriers` ด้วย array ใหม่ (เพิ่ม collider ป้ายบนทางเท้า) → physics สร้าง grid ใหม่เองตาม identity ของ array · ต้องเรียกก่อนรถ step แรก
- เสียงใช้ `uiTap` ที่มีอยู่แล้ว ไม่ได้เสนอ event ใหม่

## 3. โค้งที่หาได้ (s = เมตรจากเส้นชัยปัจจุบัน)

| # | ถนน | ทิศ | มุม | เริ่มเลี้ยว | ความกว้าง | รัศมีไลน์ | ปลอดภัย | ระดับ | PHYSICS §4.2 (grip) |
|---|---|---|---|---|---|---|---|---|---|
| 0 | แยก 224 หัวราชดำเนิน | ขวา | 95° | 710 | 12.2 | 40 ม. | 90 | 1 | 107 |
| 1 | มนัส | ขวา | 92° | 1,315 | 9.9 | 32 | 80 | 2 | 81 |
| 2 | สรรพสิทธิ์ | ขวา | 92° | 2,227 | 9.0 | 29 | 77 | 2 | 69 |
| 3 | วัชรสฤษดิ์ | ซ้าย | 90° | 2,537 | 8.4 | 31 | 79 | 2 | 67 |
| 4 | กำแหงสงคราม | ขวา | 97° | 2,662 | 8.1 | 26 | 73 | 3 | 65 |
| 5 | ราชดำเนิน | ขวา | 88° | 2,960 | 9.1 | 34 | 83 | 2 | 71 |

- สูตร: รัศมีไลน์ R = (รัศมีโค้งกลางถนน − w/2) + w / (1 − cos(θ/2)) โดย w = ความกว้างถนนช่วงตรงก่อน/หลังโค้ง − ความกว้างรถ 2 ม. · v = √(1.6 g · R)
- ตัวเลขเราสูงกว่า PHYSICS ~10% ในเมือง และต่ำกว่าที่แยก 224 (PHYSICS นับช่องเกาะกลางที่เปิดด้วย) แต่**ลำดับความยากตรงกัน** → เกณฑ์ระดับ: ≥ 88 กม./ชม. = 1 · 75–88 = 2 · < 75 = 3 (`WF.sev2Kmh/sev3Kmh`)
- HUD ขึ้นเมื่อเหลือ ≤ 200 ม. ถึงจุดเริ่มเลี้ยว · อยู่ในโค้งก่อนถึง apex แสดง "ตอนนี้"

## 4. การวางป้าย

- **บั้ง:** ยิงเส้นจาก centerline ไปด้านนอกโค้ง เจอราว/แบริเออร์/ราวคู → วางหลังราว 0.7 ม. · เจอหน้าตึก → วางบนทางเท้าห่างผนัง 0.45 ม. + collider · ที่แยก 224 บั้งอยู่ฝั่งตรงข้ามแยก (ตรงที่รถจะพุ่งไปถ้าไม่เลี้ยว) ห่างเกิน 15 ม. จึงขยายป้ายสูงสุด ×1.6
- **ขนาดใหญ่กว่าของจริง ~2 เท่า** (บั้งสูง 1.7 ม., ข้าวหลามตัด 3 ม., แผ่นข้อความ 3.4×0.85 ม.) เพราะจอมือถือเล็ก + ฝน · ขอบล่างป้ายสูง ≥ 1.2 ม. ไม่บังแผงสปอนเซอร์ (0.12–1.12 ม.)
- ป้ายเตือนล่วงหน้าอยู่ขอบซ้าย (ไทยขับชิดซ้าย) หันเข้าหารถ เอียงเข้าถนน 12°

## 5. ข้อจำกัด / ให้ conductor ตัดสิน

- ตัวอักษรแถวล่างของแผ่นข้อความ ("เลี้ยวขวา 70 ม." ใต้ "โค้งอันตราย") เล็ก อ่านออกเมื่อเข้าใกล้ ~40 ม. — ข้อความหลักแถวบนอ่านได้จากไกล
- ป้ายที่แยก 224 ยังดูเล็กจากระยะ > 80 ม. เพราะอยู่ฝั่งไกลของสี่แยกกว้าง ~40 ม. — ลูกศร HUD ช่วยตรงนี้
